## 修复：新文档带默认评论（用户暴怒）

- 根因：CommentSection 用**全局一个** localStorage key（`mybook-document-comments`），
  所有文章共用同一份评论，且读不到时对**所有**文章回退到 SEED_COMMENTS（两条种子评论）；
  首渲染 effect 又把种子写回存储。另发现这是架构 bug：A 文章的评论会出现在 B 文章。
- 改法：评论**按文档隔离**——CommentSection 加 props `{storageKey, seed?}`，
  存储键 `mybook-document-comments:<storageKey>`；种子评论只在传入 `seed` 时出现。
- 透传链：BookEditor 加 `commentKey`（默认 'default'）/`commentSeed` props → `<CommentSection>`。
  `/demo` 路由传 `commentKey="demo" commentSeed={SEED_COMMENTS}`；
  `Article.tsx` 传 `commentKey={article.id}` 不传 seed → 真实文档从「暂无评论」开始。
- 旧全局 key `mybook-document-comments` 成为孤儿数据，未迁移（本来就是共享脏数据），留在 localStorage 不影响。
- tsc -b 通过（EXIT=0）。
