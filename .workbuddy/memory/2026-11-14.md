## 粘贴图片落本地（剪贴板截图 / 网页图片）

- 新增 `src/plugins/image/pasteImages.ts`（粘贴管线）+ 服务端 `POST /api/upload/remote`（外链图代下载）。
- 三步管线：**同步插入 image 块（url 先给 blob / 原外链，粘完立刻有图）→ 异步上传（`trackUpload` 驱动进度条）→ 落盘后把 attrs.url 换成 `/media/...` 相对路径**。
- ⚠️ 换 url 必须包 `HistoryEditor.withoutSaving(editor, fn)`。`withHistory` **只往 editor 上挂了 history/undo/redo，没有挂 withoutSaving 实例方法**，
  写 `editor.withoutSaving(fn)` 是无效的（会静默变成普通 setNodes），结果按一次撤销「看着没反应」、按第二次图才消失。实测踩过。
- 入口在 `withPasteConversion.ts#insertData`，顺序：内部 slate-fragment → 先让原逻辑走；再图片文件；再 text/uri-list；最后 text/html。
  - 有 files 但 HTML 里**有可读文字**时不走「纯图片」分支（否则复制一段带图富文本会只剩图、文字全丢）。
  - `htmlToBlocks` 里 `<img>` 不再降级成 `[图片]`，改成 image 块（保留原地址），插入后用 url 匹配异步本地化
    （`insertFragment` 会重新生成 id，**不能靠 id 追踪**）。
  - `<p>文字<img></p>` 用 `runsToBlocks` 拆成「段落 + 图片块」，图片不会被吞。
- `uploadImage.ts` 导出 `loadImageSize` / `MAX_DISPLAY_WIDTH` / `fitDisplaySize`，新增 `trackUpload`（模拟爬到 88% 封顶，真实 Promise 落地才冲 100 并移除遮罩）。
- 服务端：校验协议只允许 http/https、拒绝内网/回环（SSRF）、15s 超时、25MB 上限、content-type 白名单映射扩展名、带 UA+Referer 过防盗链。
- 验证（CDP）：截图粘贴 → 落 `data/media/images` 且节点变相对路径；撤销**一次**即可撤掉整张图；
  网页 `<img>` 粘贴 → 服务端代下载落盘；带图富文本 → 文字与图片都在；进度条 40ms 可见「图片上传中 0%」、完成后 240ms 消失。
