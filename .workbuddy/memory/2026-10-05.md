## 空段落「＋」直接铺开块/插件插入面板

需求：DocBar 悬停在**空段落**（图标为「+」）时，不要先弹整个块操作菜单再点「在下方插入」，
而是直接把块类型选择面板（BlockTypePicker，含流程图 DRAWIO / 画板 DRAWBOARD 等）铺开，
选中即在空行**原地插入**（替换该空行，不留空行）。

改动文件：`src/plugins/context-menu/ContextMenu.tsx`（仅此一个）

1. 新增 `isTargetEmptyParagraph`：`type===PARAGRAPH && !attrs.lilist && children.length===1 && children[0].text===''`。
   - 必须排除挂 lilist 的空列表项（列表项 DocBar 图标是列表图标，不是「+」）。
   - 判定与 `ElementWrapper` 的 `data-empty` / `Paragraph.tsx` 的 isEmpty 语义对齐。
2. `handleInsertBlock` 锚点逻辑：空段落时 `anchorPath = getTargetPath()`（悬停的那个空行），
   不再被「光标所在的另一空行」抢锚点；其它块沿用原逻辑。
   - 之后 `isAnchorEmpty` → `removeNodes` 原地替换，逻辑复用不变。
3. 渲染分支：`isTargetEmptyParagraph` 时提前 return，menu 内容只渲染 `<BlockTypePicker onSelect={handleInsertBlock} />`
   （`renderChartFlow`/`renderEmbedFlow` 仍保留）。非空块走原菜单（含「在下方插入」Popover）。

关键背景（本项目约定）：

- 编辑器基于 **Slate**；块都有 `id/type/attrs/children`。
- DocBar（左侧悬浮图标）由 `DocBar.tsx` 渲染，`onMouseEnter` 调 `openMenu(id,x,y)` 打开
  `ContextMenu`（menu-context 的 `MenuContext`）。**是 hover 打开，不是 click。**
- 「空」判定：`ElementWrapper` 打 `data-empty` 属性 → `DocBarContext` 读取为 `activeElement.isEmpty`。
- `createBlockNode`（block-picker/block-nodes.ts）负责按类型构造合法节点。

已知的**既有**类型错误（非本次引入，`tsc -b` 会报）：

- `withPasteConversion.ts`、`inline-comment/mark.ts` 一批 Slate `Node` / DOM `Node` 命名冲突报错。
  → 说明本仓库当前 `tsc -b` 不干净；改完用 `node node_modules/typescript/bin/tsc -b | grep <改动文件>` 过滤即可。

## 国际化：增补 5 种语言 + 首批界面文案（顶栏 / 设置下拉）

需求：先「一点点来」，把截图里几处 i18n：顶栏搜索框 placeholder、右上角「设置」按钮、
设置下拉首页各块（查找替换/字体/主题/光标/模式/语言 + 右侧当前值）；
同时语言从「中/英」扩到 **7 种**：zh、zh-TW、en、ja、ko、fr、de。

项目 i18n 现状（约定）：

- 基于 **i18next + react-i18next**；入口 `src/i18n/index.ts`，词条在 `src/i18n/locales/*.ts`（默认导出 + `as const`）。
- 语言状态由 `src/context/LanguageContext.tsx` 封装（`useLanguage()` → language/setLanguage/toggleLanguage）。
- 设置 UI 在 `src/components/SettingsSwitcher/index.tsx`（一个下拉，内部 `view` 状态机：
  home/font/theme/cursor/wallpaper，本次新增 `language` 子视图）；顶栏搜索框在 `src/App.tsx` 的 `HeaderSearch`。
- 注意：`SettingsSwitcher` 已是唯一语言入口；`src/components/LanguageSwitcher/index.tsx` 是**遗留未引用**组件（顺手改成用短码，避免误导）。

本次改动：

1. `src/i18n/index.ts`：注册 7 种语言；导出 `AppLanguage`（联合类型）、`SUPPORTED_LANGUAGES`、
   `LANGUAGE_SHORT`（触发按钮/行右侧短码：中/繁/EN/日/한/FR/DE，不随当前语言变）。
   新增：localStorage 记忆语言（key `mybook-language`）+ `languageChanged` 时同步 `<html lang>`。
   ⚠️ `STORAGE_KEY`/`readStoredLanguage` 必须定义在 `i18n.init()` **之前**，否则 init 里读它会 TDZ 崩。
2. 词条：`zh.ts`/`en.ts` 追加 `header.searchPlaceholder`、`settings.*`、`themePresets.*`、`cursorThemes.*`、`languages.*`；
   新建 `zh-TW.ts`/`ja.ts`/`ko.ts`/`fr.ts`/`de.ts`（含 toast/fontSwitcher/findReplace/drawboard + 上述新键；
   **唯独没翻 colorPicker 那 ~70 个颜色名**，会 fallback 到 zh——后续要补）。
   - `languages.*` 刻意写各语言**原生名**（简体中文/繁體中文/English/日本語/한국어/Français/Deutsch），七份文件里都一样。
   - 法语文件注意：单引号字符串里用**弯引号 ’**，别用直引号。
3. `LanguageContext.tsx`：`normalizeLng` 支持 7 种 + `zh-Hant/zh-HK/TW` 变体归一；`toggleLanguage` 改为在 SUPPORTED 里循环。
4. `SettingsSwitcher/index.tsx`：触发器/各行标签用 `t()`；主题值 `t('themePresets.'+id)`、
   光标值/描述 `t('cursorThemes.'+id+'.name'/'.desc')`、模式值 `t('settings.modeEdit/modeRead')`；
   语言行由「点击即切换」改为**进入 `language` 子视图**，列出 7 种语言（选中打勾，onClick `setLanguage`）。
   主题列表里黑主题（`BLACK_THEME_ID`）特判 → `t('themePresets.blackDark')`（原来靠下标 `i===11`，已去掉）。
5. `App.tsx`：`HeaderSearch` 用 `t('header.searchPlaceholder')`。
